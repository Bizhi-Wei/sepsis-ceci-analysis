# R dependencies

The Windows verification uses R 4.6.1. The eICU scripts use pROC, ggplot2, cowplot, readr, and jsonlite. The MIMIC scripts also use tidyverse, survival, patchwork, gridExtra, boot, and scales. The expression scripts also use limma, fgsea, glmnet, Biobase, AnnotationDbi, org.Hs.eg.db, hgu133plus2.db, and ggrepel. Install Bioconductor packages for the R and Bioconductor versions used. Base R provides parallel and splines.
