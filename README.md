# CECI and early mortality in sepsis

This source snapshot accompanies *Early Clinical Endothelial-Coagulopathy Index Trajectories and Mortality in Sepsis*. It provides R and Python programs for the MIMIC-IV prognostic analyses, the distinct eICU in-hospital mortality assessment, and the GEO expression analyses.

## Data access

Obtain individual credentialed access to [MIMIC-IV v3.1](https://physionet.org/content/mimiciv/3.1/) and [eICU-CRD v2.0](https://physionet.org/content/eicu-crd/2.0/) from PhysioNet under the applicable data-use agreements. The clinical scripts create restricted local cohorts, patient-level outputs, and fitted transformations. Store the working directory outside the repository. The published studies and version identifiers are linked on the dataset records.

The blood expression sources are [GSE65682](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE65682) and [GSE95233](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE95233). The original workflow used preprocessed ExpressionSets and the GPL13667 ADF annotation. Place the same verified local inputs in `01_data/raw` under the work directory. The included checksums identify the exact source artifacts from the analysis. A new download of the original GEO series may be packaged differently. Exact regeneration of the serialized ExpressionSets from the accession pages has not been verified.

Obtain the matching Hallmark and Reactome GMT inputs separately under their terms and place them under `01_data/pathways`. Confirm both checksums before using them. The archived analysis used `h.all.symbols.gmt` and `reactome2022.gmt`. The files and their hash values are listed in `public_input_checksums.sha256`.

## Local configuration

Create an existing private directory and set `CECI_WORK_DIR` to it. Set `MIMIC_DIR` to the credentialed MIMIC-IV root containing `hosp` and `icu`. The MIMIC extraction expects the original uncompressed CSV filenames. Set `EICU_DIR` to the credentialed eICU-CRD v2.0 root. The eICU extractor accepts flat CSV, flat CSV.gz, or a same-named CSV inside a CSV directory. Run the R commands with Rscript. Python and R dependency notes are in `requirements.txt` and `R_dependencies.md`.

## Analysis entry points

1. MIMIC-IV cohort and associations. Run `03_extract_mimic_sepsis_cohort.py` and `04_mimic_cox_iptw_and_figures.R`.
2. Fluid and trajectory analyses. Run `05_extract_dynamic_and_fluid_tte.py`, `04b_fluid_tte_and_longitudinal_landmarks.R`, `06_mimic_target_trial_and_trajectory_models.R --tables-only`, `04c_incremental_discrimination_nri_idi.R`, `06_mimic_target_trial_and_trajectory_models.R`, and `08_time_varying_ceci_sensitivity.R` in that order. The historical script names are kept for traceability. Their current outputs report prognostic and exploratory observational associations.
3. eICU fixed-score assessment. After MIMIC extraction, run `eICU/extract_external_score.py` and `eICU/assess_external_score.R` from `scripts`. The extraction estimates the CECI transform from the MIMIC development cohort locally, then applies it to the eICU panel. The eICU endpoint is in-hospital mortality after the Hour-24 landmark.
4. Blood expression analysis. Run `01_download_and_annotate_geo.R` on the verified ExpressionSets. Before running `02b_revalidate_eimrs.R`, place the manuscript's GEO-only reference tables `Table_4_Locked_EIMRS_Signature_Genes.csv` and `Table_S8_EGIH_Univariate_Cox_GSE65682.csv` in `03_results/tables` in your work directory. They supply the locked coefficient check and the original pathway gene order. Then run `02b_revalidate_eimrs.R` and `02_transcriptomic_endothelial_signature.R`. Full development validation defaults to 1,000 bootstrap replicates. The figure and table filenames generated by the scripts use analysis numbering. The JICM manuscript places the clinical figures first.

This snapshot changes the location of inputs and outputs and removes the automatic download of legacy ExpressionSets. It reads the frozen GEO coefficient check from the matching aggregate reference table. The clinical and eICU analysis rules retain the original definitions. Read the validation note for the checks performed on this snapshot.
